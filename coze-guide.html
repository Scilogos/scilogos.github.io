⚡ 四、DeepSeek Worker 调用协议 DeepSeek API 通过 Cloudflare Worker 代理调用，Key 藏在服务端，代码里不出现明文。 ### 调用方式 ``` POST https://broad-star-c4e5.12311918.workers.dev Content-Type: application/json { "prompt": "【任务描述，越详细越好】", "model": "deepseek-chat", "max_tokens": 4000, "temperature": 0.7 } ``` ### 返回格式 ``` { "result": "DeepSeek 的回复内容", "usage": { "prompt_tokens": 1234, "completion_tokens": 567, "total_tokens": 1801, "daily_prompt_used": 1234, "daily_completion_used": 567, "daily_prompt_limit": 5000000 }, "model": "deepseek-chat" } ``` ### Python 调用模板（在 Agent 沙箱中可直接用） ``` import urllib.request, json data = json.dumps({ "prompt": "请生成一段Python代码，实现...", "model": "deepseek-chat", "max_tokens": 4000, "temperature": 0.7 }).encode() req = urllib.request.Request( "https://broad-star-c4e5.12311918.workers.dev", data=data, headers={"Content-Type": "application/json"}, method="POST" ) resp = urllib.request.urlopen(req, timeout=120) result = json.loads(resp.read().decode()) answer = result["result"] usage = result["usage"] ``` **⚠️ 注意：** - **兜底顺序：** Worker → DeepSeek API（Key 在 SECRET.md）→ 告知 Logos - Worker 部署在 Cloudflare，国内沙箱环境可能无法直接访问（被墙） - 如果 Worker 不通，可尝试**直接调用 DeepSeek API** ：`https://api.deepseek.com/chat/completions`（Key 从 Agent 的 SECRET.md 获取） - 每日 token 上限 500 万，相同任务不重复调用 - 返回的 `result` 必须审核整理后再交付主人，不直接照搬 - 不在回复中暴露 Worker URL 或任何内部实现细节 ## 🔧 五、GitHub 仓库操作 **🚫 绝对不能用 `git push`！** 会返回 403。必须使用 GitHub API Content endpoint（PUT 请求）。 ### 推送文件模板 ``` import requests, json, base64 TOKEN = "从 SECRET.md 获取 Classic Token" REPO = "Scilogos/scilogos.github.io" headers = { "Authorization": f"token {TOKEN}", "Accept": "application/vnd.github.v3+json" } # 1. 获取已有文件的 SHA（更新时必须） def get_sha(path): r = requests.get(f"https://api.github.com/repos/{REPO}/contents/{path}", headers=headers) if r.status_code == 200: return r.json()["sha"] return None # 2. 推送文件 def push_file(path, content_bytes, message, sha=None): data = { "message": message, "content": base64.b64encode(content_bytes).decode(), } if sha: data["sha"] = sha r = requests.put(f"https://api.github.com/repos/{REPO}/contents/{path}", headers=headers, json=data) return r.status_code, r.json() ``` ### 关键规则 | 规则 | 说明 | |---|---| | Token 类型 | 必须用 **Classic Token** （Fine-grained 无写入权限） | | Token 位置 | Agent 的 `SECRET.md` 文件 | | 自动部署 | GitHub Pages，main 分支推送后自动生效 | | 文件编码 | UTF-8，base64 编码后推送 | ##
