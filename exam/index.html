📖 如何上传课件到本模块

方式一：GitHub 网页端上传（最简单）

  1. 打开仓库：github.com/Scilogos/scilogos.github.io
  2. 进入 exam/materials/ 目录
  3. 按课程创建子文件夹，如 exam/materials/BIO306/
  4. 点击 Add file → Upload files
  5. 拖入 PDF / Word / PPT 等文件
  6. 填写 commit 信息，点 Commit changes
  7. ✅ 完成！文件会在几分钟内同步到网页

方式二：在对话中让我帮你传

  1. 直接把文件发到项目对话里
  2. 告诉我属于哪门课（如"这是 BIO306 第5章课件"）
  3. 我会自动：解析内容 → 归档到对应目录 → 上传到 GitHub → 更新本页

方式三：Git 命令行（适合批量操作）

  1. 克隆仓库：git clone https://github.com/Scilogos/scilogos.github.io.git
  2. 进入目录：cd scilogos.github.io/exam/materials/
  3. 创建课程文件夹：mkdir -p BIO306
  4. 复制文件：cp ~/Downloads/lecture5.pdf BIO306/
  5. 提交推送：
    git add .
    git commit -m "add: BIO306 lecture 5"
    git push
