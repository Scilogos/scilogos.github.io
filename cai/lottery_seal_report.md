## 二、实验全景

### Phase 1: 数据采集与基线建立 ✅
- 排列3: 7633期(2004~2026-06-17)，体彩官方API
- 福彩3D: 4663期(2013~2026-17)，福彩官方API
- 模拟数据: 2192期(2020~2025)，seed=42，支持batch_generate多种子

### Phase 2: 对照组 — 传统ML"找规律" ✅
- **结论**：LGBM单号命中率9.66% ≈ 随机10%，Top-K有微弱信号但不足以盈利
- **方法**：LightGBM直选预测 + 特征工程(12维)
- **关键数据**：top-10命中率0.97% vs 期望1.00%

### Phase 3: 对抗博弈模拟 v1 ✅
- **K策略**（5精英Agent）vs **R策略**（60进化Agent）vs 庄家
- **核心发现**：对抗庄家下庄家利润率从48%暴涨至75%+；K策略ROI=-92%
- **结论**：完全对抗条件下策略反而有害

### Phase 4: 严格预测能力检验 ✅
- 4个Phase检验ML能否超越随机基线
- **Phase1**：10种子模拟命中率0.1031 ≈ 10%，p=0.207
- **Phase4**：排列检验 **p=0.533**
- **结论**：传统"找规律"路线彻底失败，ML无法超越掷骰子

### Phase 5: 深化对抗实验 ✅
- **噪声扫描**：庄家噪声≥30%时K策略开始存活，但仅存活不盈利
- **信息不对称**：庄家只看随机彩民时，庄家利润率-3152%，R策略ROI+13031%
  - ⚠️ 唯一盈利条件，但**现实中不可能**实现（庄家必然看到策略彩民）
- **协调博弈**：K策略协调投注无效（规模归零）

### Phase 6: 元叙事博弈模拟 ✅
- 6组训练，每组100个进化Agent（10种类型），6种庄家策略
- **生态差异显著**：不同庄家策略塑造不同Agent生态
  - 组1(cold_preference)唯一正ROI(+0.091)，类型分布最均衡
  - 组0(min_payout)gap_hunter垄断62%，生态崩溃
- **真实数据验证**：
  - 总体概率比=0.9706（低于随机！）
  - 排列检验 p=0.280（不显著）
  - 无任何组单独显著超越随机
- **结论**：元叙事路线不支持"庄家操控规律"假说

## 三、最终结论

### 排列3不存在可利用的统计规律

| 实验路线 | 核心问题 | p值 | 结论 |
|----------|----------|-----|------|
| 传统ML | 能否找到号码规律？ | 0.207 | 不能 |
| 严格检验 | ML能否超越随机？ | 0.533 | 不能 |
| 对抗博弈 | 策略对抗庄家能否盈利？ | — | 不能（ROI=-92%） |
| 信息不对称 | 完美信息能否盈利？ | — | 能，但不可实现 |
| 元叙事模拟 | 学习庄家规律能否超越随机？ | 0.280 | 不能 |

### 三条路全部走死

1. **"找规律"路线**：ML预测能力 ≈ 掷骰子（p=0.533）
2. **"对抗庄家"路线**：对抗反而被庄家利用，策略越强越亏
3. **"学习庄家"路线**：模拟中学到的规律无法迁移到真实数据（概率比<1）

### 唯一盈利窗口不可达

信息不对称实验证明：如果庄家看不到策略彩民，ROI可达+13031%。但现实中庄家必然掌握全市场投注分布，这个窗口在物理上不可实现。

## 四、方法论沉淀

虽然结论是"不可盈利"，但本项目的**方法论有复用价值**：

### 1. 双轨工作流
- GitHub云端存档 + 本地PyCharm执行
- 脚本一式两份，数据双向同步

### 2. 模拟-验证范式
- 模拟数据 → 对照组基线 → 实验组突破 → 真实数据验证
- 排列检验(permutation test)是检验预测能力的金标准

### 3. 对抗博弈框架
- 庄家策略变体 × Agent类型多样性 × 进化选择
- 可直接迁移到股票市场模拟

### 4. 元叙事模拟架构
- **多生态系统并行训练**：不同庄家/市场环境 → 差异化Agent群体
- **多样性保护**：生态位保留+移民注入，防止进化收敛
- **3种聚合策略融合**：等权平均+投票法+置信度加权
- **在线微调**：验证阶段持续适应新数据
- **→ 可迁移到股票**：将庄家替换为市场maker/机构行为模型，Agent替换为交易策略

## 六、封存原因

1. **结论明确**：6组实验从3条路线一致得出"不可盈利"结论
2. **无剩余探索空间**：唯一盈利窗口(信息不对称)在现实中不可实现
3. **边际收益为零**：更多实验只会重复同一结论
4. **资源应转向**：股票量化存在真实可利用的市场 inefficiency
