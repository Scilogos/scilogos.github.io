## 一、研究核心

### 1.1 核心问题

**A股市场是否存在可通过对抗学习发现且可迁移至真实交易的可利用结构？**

彩票项目已证伪：在纯随机系统中，ML预测与掷骰子无统计差异（p=0.533）。但股票市场的本质区别在于——价格不是上帝掷骰子，而是多方博弈的均衡结果。博弈必有策略，策略必有结构，结构是否可学习、可利用、可迁移，是本研究的核心问题。

### 1.2 核心假设

**H1（结构假设）**：市场参与者（机构/游资/散户）的行为模式在时间序列中留下统计可识别的结构性痕迹。

**H2（可学习假设）**：对抗学习框架（Generator-Discriminator-Strategy Agent闭环）能够发现并利用这些结构。

**H3（可迁移假设）**：在虚拟市场中习得的策略能力可以迁移到真实数据上，即虚拟环境中的表现与真实表现正相关。

**零假设 H0**：市场参与者的行为痕迹要么不存在（EMH强式有效），要么存在但不可学习（噪声>>信号），要么可学习但不可迁移（虚拟环境≠真实市场）。

### 1.3 与彩票项目的方法论继承与突破

| 维度 | 彩票项目结论 | 股票项目设计 |
|------|-------------|-------------|
| 数据性质 | iid伪随机 | 非平稳、自相关、regime切换 |
| 对抗学习价值 | 零（p=0.280迁移失败） | 待验证——生成器是关键变量 |
| 迁移风险 | 证实不可迁移 | 需排列检验严格把关 |
| 核心教训 | **模拟中学的规律≠真实的规律** | 每个Phase必须有真实数据交叉验证 |
| 新增核心能力 | 无 | **生成器（TimeGAN）——创造虚拟训练场** |

**关键突破点**：彩票项目没有生成器，Agent直接在真实开奖上训练→过拟合→迁移失败。股票项目先建生成器创造"逼真的虚拟市场"，让Agent在虚拟环境中充分进化，再用排列检验验证迁移性——这是方法论上最核心的升级。

### Phase 1：生成式对抗学习 — 虚拟市场生成器 🔄 进行中

**目标**：训练TimeGAN生成"以假乱真"的股票价格序列

#### 1.1 架构

TimeGAN（Yoon et al., 2019）五组件：

```
噪声 z → Generator(GRU) → Supervisor(GRU) → Recovery(GRU+FC) → 生成序列
                                                              ↕
真实序列 → Embedder(GRU) → 潜空间 h ← Discriminator(MLP) 判真/假
```

**训练三阶段**：
- Phase A（自编码器预训练）：Embedder+Recovery学习压缩-还原
- Phase B（监督训练）：Supervisor学习step-wise状态转移
- Phase C（联合对抗训练）：G+S+E+R联合优化，D对抗判别

#### 1.2 已发现并修复的致命Bug

| Bug | 根因 | 表现 | 修复 |
|-----|------|------|------|
| Phase C梯度断裂 | `h_gen_supervised.detach()`切断G→S→D梯度链 | D_loss→0, G_loss→5+ | 拆为forward_discriminator(detach) + forward_generator(不detach) |
| Supervisor优化器缺失 | Phase C生成器步未更新opt_supervisor | S无法进化 | 加入opt_supervisor.zero_grad()+step() |
| 训练数据量不足 | csv_files[:50]硬编码 | 4919只只用了50只 | --max-stocks参数，默认0=全部 |

#### 1.3 验证标准（三级递进）

**Level 1 — 统计分布匹配**：
- 收益率分布的均值/方差/偏度/峰度 vs 真实数据
- 自相关函数(ACF)匹配度
- 波动率聚集效应（GARCH特性）

**Level 2 — 判别器测试**：
- 独立Discriminator区分真实vs生成
- 准确率应≈50%（随机猜测水平）
- >70%说明G太弱，<40%可能有数据泄露

**Level 3 — 下游任务等价**：
- 在真实和生成数据上分别训练同一预测模型
- Out-of-sample表现应统计等价
- 这是最高标准：不仅"看起来像"，而且"用起来一样"

**开盘重点验证**（区别于平均评价）：
- 9:30-9:40时段权重5x（开盘波动最大，信息密度最高）
- 9:40-9:50时段权重2x
- 其余时段权重1x
- 核心理念：开盘30分钟是A股信息含量最高的时段，生成器如果在这里不过关，其余再好也没用

#### 1.4 特殊场景

**早盘模拟（9:15-10:00）**：
- 独立于TimeGAN，按A股开盘规律建模
- 9:15-9:25：集合竞价（价格收敛+成交量递增）
- 9:25-9:30：静默期（极低成交）
- 9:30-9:40：开盘爆发（3x波动+3x成交量+指数衰减）
- 产出：premarket_simulated.npy + premarket_meta.json

**生成数据管理**：
- 模型（.pt文件）：保留，可清空重来
- 生成数据（.npy文件）：支持清除+再生
- 诊断脚本generator_diagnostic.py：4测试模块（pipeline/clear/premarket/open-focus）

### Phase 2：策略Agent进化场 ⏳ 待开发

**目标**：在虚拟市场中进化多样化的交易策略群体

#### 2.1 Agent设计

从彩票元叙事架构迁移，角色映射：

| 彩票角色 | 股票角色 | 行为特征 |
|----------|----------|----------|
| 庄家 | 做市商Agent | 提供流动性，设定买卖价差，模拟机构行为 |
| 博弈彩民 | 主动策略Agent | 基于信号预测交易，目标是超越市场 |
| 机选彩民 | 噪声交易者 | 随机交易，提供市场噪声 |
| 冷号偏好 | 价值策略Agent | 偏好低估值/冷门标的 |
| 热号偏好 | 动量策略Agent | 追涨杀跌 |
| gap_hunter | 均值回归Agent | 利用价格偏离 |

#### 2.2 做市商模型

做市商是市场的"庄家"，决定价格如何对交易行为反应：

1. **逆向提供流动性**：买多时提高卖价（标准做市商）
2. **趋势跟随**：放大趋势（模拟追涨杀跌的机构）
3. **均值回复**：价格偏离时反向操作（价值型机构）
4. **Regime切换**：根据市场状态动态切换策略

#### 2.3 进化机制

**R策略（进化算法）**：
- 初始60个随机策略Agent
- 每轮在虚拟市场中运行一个季度
- Top 20%保留，Bottom 30%淘汰
- 淘汰位由变异体+杂交体填充

**K策略（精英训练）**：
- 5个手工设计的策略骨架
- 在多市场环境下超参优化
- 作为R策略的对手和参照

#### 2.4 与stocks3.py的集成

- FeatureExtractor（BB特征提取器）→ 策略Agent的特征输入
- 信号系统（多因子评分+信号门控）→ 策略Agent的决策骨架
- 元叙事模块骨架（MarketEcosystem/TradingAgent/MetaSignalGenerator）→ 进化场基础
- ML模块（LightGBM）→ K策略候选

### Phase 3：真实数据验证与排列检验 ⏳ 待开发

**目标**：严格验证虚拟市场中习得的能力是否可迁移到真实数据

> 彩票项目的核心教训：模拟中学到的规律不一定能迁移到真实数据。必须用排列检验把关。

#### 3.1 迁移验证三重门

**第一重：Walk-forward回测**
- 训练期：2018-2024
- 验证期：2025
- 测试期：2026
- 要求：测试期夏普比率>0.5，最大回撤<25%

**第二重：排列检验（Permutation Test）**
- 真实策略收益 vs 1000次打乱信号后的收益分布
- p<0.05 → 策略有效（拒绝"策略只是运气"的零假设）
- p≥0.05 → 过拟合（策略在生成数据上学到的模式不存在于真实数据）

**第三重：跨市场验证**
- 在不同行业/板块/市值区间分别检验
- 至少3个不同板块通过排列检验
- 防止策略只对特定行业有效

#### 3.2 输出规格

用户指定目标股票后输出：
1. **拟合曲线**：策略预测vs实际价格，带置信区间
2. **交易信号**：买入/卖出/持有 + 信号强度
3. **风控指标**：最大回撤/夏普比率/胜率/盈亏比
4. **显著性**：排列检验p值（策略是否显著超越买入持有）

#### 3.3 可能的研究结论

| 情景 | 含义 | 下一步 |
|------|------|--------|
| 排列检验通过(p<0.05) | 对抗学习发现的策略结构真实存在 | 进入Phase 4常驻系统 |
| 部分板块通过 | 策略结构仅存在于特定市场结构 | 分析通过的板块共性，缩小应用范围 |
| 全部不通过(p≥0.05) | 虚拟环境无法模拟真实市场的关键结构 | 回到Phase 1改进生成器，或调整H1假设 |
| 生成器L2验证不过 | 生成数据不够逼真 | 改进TimeGAN架构或换用CVAE/Diffusion |

## 这个项目到底在干嘛？

### 一句话版本

> 让AI学会"造假行情"，然后在假行情里训练交易策略，最后看看在真行情里能不能赚到钱。

### 三句话版本

1. **造假**：训练一个AI（生成器），让它能造出"连专家都分不清真假"的股票K线图
2. **练兵**：让一堆交易策略AI在这个假市场里互相厮杀进化，活下来的就是最强的
3. **验证**：把活下来的策略放到真实A股数据上，用统计方法检验它是不是真的有效——还是只是在假数据上运气好

### 为什么要这样做？

**彩票项目的教训**：我们之前用同样的方法研究彩票，发现AI在模拟数据上表现很好，但一放到真实数据上就拉胯（p=0.280）。原因很简单——模拟中学到的"规律"在现实中根本不存在。

**股票不一样**：彩票开奖是上帝掷骰子，股票涨跌是几亿人博弈的结果。博弈就有策略，策略就有痕迹。但这个痕迹能不能被AI学到？这是我们要回答的问题。

### 第二步：训练"造假大师"（进行中 🔄）

训练一个TimeGAN生成器，让它学会造出逼真的股票行情。

**人话解释**：想象一个假钞制造者——

- **Phase A（学画线条）**：先学会把真钞压缩成简码，再从简码还原回去。这练的是基本功——理解真钞长什么样。
- **Phase B（学顺序）**：学会"这一笔画完下一笔该画什么"。这练的是时间感——真钞不是随机涂的，是有先后逻辑的。
- **Phase C（骗过验钞机）**：造假钞，让验钞机（判别器）分不清真假。验钞机越强，造假者也被逼越强。两者互相进化。

**遇到的坑**：Phase C有个致命bug——造假者把假钞递给验钞机的时候，不小心切断了反馈链。验钞机说"这是假的"，但造假者听不到。结果验钞机轻松识破（准确率≈100%），造假者永远学不会改进。修了这个bug后，两者才能真正对抗进化。

**怎么判断造假水平**：
- L1（统计检验）：造出来的行情，均值/波动率/偏度/峰度跟真实的一样吗？
- L2（验钞机测试）：拿一个新验钞机来验，准确率≈50%才算及格（等于瞎猜）
- L3（实战检验）：用真行情和假行情分别训练同一个预测模型，效果一样才算优秀

**特别关注**：开盘前30分钟（9:30-10:00）的生成质量。A股开盘波动最大、信息最多，造假最难。这里过关才是真过关。

---

### 第三步：虚拟市场大逃杀（待开发 ⏳）

在假行情里放一群交易策略AI，让它们互相竞争进化。

**人话解释**：造了一个虚拟赌场——

- **做市商**（庄家）：决定买卖价差，模拟机构行为
- **动量策略**（追涨杀跌）：看涨了就买，看跌了就卖
- **价值策略**（抄底逃顶）：跌多了就买，涨多了就卖
- **均值回归**（波动猎手）：价格偏离均值就反向操作
- **噪声交易者**（散户）：随机买卖，提供市场噪音

**进化机制**：每一轮"季度"交易后，赚最多的前20%活下来，亏最多的30%淘汰。淘汰的空位由"变异"（微调参数）和"杂交"（两个好策略的组合）来填充。几十轮下来，活下来的策略就是在假市场里最能打的。

---

### 第四步：拉回现实检验（待开发 ⏳）

把虚拟赌场里活下来的策略，拉到真实A股数据上检验。

**为什么这步最关键**：彩票项目的血泪教训——模拟赌场里的赌神，在真赌场可能一文不值。

**检验方法（排列检验）**：
1. 看看策略在真实A股上赚了多少
2. 把策略的交易信号随机打乱1000次，每次也跑一遍
3. 如果真实收益显著高于打乱后的收益分布（p<0.05），说明策略确实学到了东西
4. 如果打乱后差不多，说明策略只是运气好，或者只是在假数据上过拟合了

**可能的结果**：

| 结果 | 含义 | 怎么办 |
|------|------|--------|
| 排列检验通过 | AI真的发现了可利用的市场结构 | 🎉 进入实用阶段 |
| 部分通过 | 只在某些板块有效 | 缩小范围，搞清楚为什么 |
| 全不通过 | 虚拟环境无法模拟关键结构 | 改进生成器，或者接受"市场可能真的接近有效" |

**即使全不通过，也不是失败**——我们至少知道了：在当前生成器水平下，虚拟市场训练的策略不能直接用于实战。这本身就是一个有价值的研究结论。

---

## 最坏情况和最好情况

**最坏情况**：生成器造不出逼真行情（L2验证不过），或者策略在假数据上过拟合了（排列检验不通过）。结论：当前方法行不通，需要更好的生成器或不同的方法论。

**最好情况**：生成器通过L3验证，进化策略通过排列检验，且跨板块有效。这意味着对抗学习确实能发现市场的可利用结构——从学术和实用角度都很有价值。

**最可能的情况**：生成器L1/L2能过，L3勉强；策略在某些板块通过排列检验，某些不通过。需要具体分析哪些板块有什么特殊的结构特征。
