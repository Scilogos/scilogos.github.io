================================================================

================================================================

扫描全A股列表，生成stock_list.json

下载日K线（--resume跳过已有不会重复下）

【v2.1新增机制】训练时自动包含：
  ★ 神经元放电: 63.21%(1-1/e)阈值全或无行情
  ★ 涨跌停板: 主板±10%/创业板±20%/ST±5%/北交所±30%
  ★ 市场冲击模型: 大单滑点+永久性冲击(Almgren-Chriss)
  ★ T+1约束: 散户当日买入不可卖出
  ★ 隔夜跳空: 模拟集合竞价缺口
  ★ 庄家阶段状态机: 吸筹↔拉抬↔震仓↔派发
  ★ 市场状态检测: 趋势/震荡/转折三态
  ★ 放电感知: 庄家/散户/游资各有感知强度

================================================================
  Phase 5：实盘反馈
================================================================

【反馈文件格式】feedback.txt，每行一条，| 分隔：
# 日期 | 方向 | 代码 | 价格 | 数量 | 盈亏 | 备注
# 方向填：买入 或 卖出
# 盈亏填：卖出时写实际盈亏金额，买入时写0
# 备注随便写（止损/止盈/追高/抄底 等）
2026-06-23 | 买入 | 600519.SH | 1800.50 | 100 | 0 | 茅台，系统看多
2026-06-24 | 卖出 | 600519.SH | 1835.20 | 100 | 3470 | 茅台止盈
2026-06-25 | 买入 | 000001.SZ | 12.35 | 1000 | 0 | 平安银行
2026-06-26 | 卖出 | 000001.SZ | 11.80 | 1000 | -550 | 止损出局

生成示例反馈文件（第一次用，先看看格式）
python feedback_processor.py --mode demo

只解析看看反馈文件内容对不对
python feedback_processor.py --mode parse

评估信号准确率（胜率/盈亏比/个股表现）
python feedback_processor.py --mode evaluate

生成校准参数（根据实盘结果调整庄家/散户/奖励参数）
python feedback_processor.py --mode calibrate

全流程：解析+评估+校准+出报告（推荐用这个）
python feedback_processor.py --mode full

只出报告（Markdown格式，人可读）
python feedback_processor.py --mode report

【监察脚本会检查的项目】
  数据层: 文件数/质量/行业分类
  生成器: 模型文件/训练历史/loss下降
  对抗训练(重点):
    - 模型是否存盘
    - Agent持仓是否在变(不是空转)
    - 奖励是否非零(有学习信号)
    - 庄家是否真的执行防共四策
    - 散户是否有类型差异(不是全部一样)
    - 策略多样性是否在变化
    - 价格轨迹是否有波动(不是一条直线)
    ★ 神经放电是否触发(不是永远静息)
    ★ 涨跌停是否生效(价格不超限)
    ★ 市场状态是否有转换
    ★ 庄家阶段是否有切换
    ★ 代码完整性: 关键类/阈值/T+1等是否齐全
    ★ 市场真实性: 涨跌停/冲击模型/跳空/阶段机
  解读器: 报告/信号/排列检验
  反馈闭环: 校准参数/trainer_state

退出码: 0=全部通过, 1=有失败项
  可在PowerShell中判断: if ($LASTEXITCODE -eq 0) { "健康" } else { "有问题" }

================================================================
  ★ 常见问题排查
================================================================

【Baostock连接中断/WinError】
  症状: 下载到一半卡住，报WinError或连接中断
  原因: Baostock长连接1.5小时后断线
  修复: v2.0已加入30秒超时+断线重连+3次重试
  手动恢复: 重新跑同一命令，--resume会跳过已下载的

【周末/假日查不到数据】
  症状: scan返回0只股票
  原因: 日期落在周末/假日，Baostock无数据
  修复: v2.0已改为回溯7天逐个尝试找交易日

【行业分类全部分到"未知"】
  症状: classify跑完只有1个"未知"行业
  原因: 旧版代码读错字段(把股票名当行业名)
  修复: v2.0已改为直接读row[2]+优先取申万分类
  断点续传: 每100只自动存，重跑自动跳过已分类的
  如需重来: 先删除 stockdata/industry_classification.json

【行业分类卡住/超时】
  症状: classify到某只卡住不动
  修复: v2.0已去掉线程超时(会破坏Baostock连接)，改用同步+断点续传

【对抗训练reward全零/价格不动】
  症状: 庄散对抗看起来在跑但没有学习
  排查: python pipeline_monitor.py --focus adversarial --verbose
  常见原因:
    - update_portfolio没被调用 → v2.1已修复(每步调用)
    - OrderBook死锁(买卖单都不动) → v2.1防摆烂五方案
    - 散户策略全部退化成一样的 → v2.1多样性检查+噪声注入
    - 神经放电永远不触发 → 检查买卖压力是否正常累积

【文件名_dotpy_前缀】
  从项目下载的文件会带_dotpy_前缀，需改名才能import
  批量改名: Get-ChildItem "_dotpy_*.py" | Rename-Item -NewName { $_.Name -replace '^_dotpy_','' }
