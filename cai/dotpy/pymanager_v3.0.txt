### 竞技场概述

多组合进化竞技场同时训练8种不同参数的庄散组合:
- 短线追涨 (short_momentum): 1日预测，专长追涨
- 短线杀跌 (short_panic): 1日预测，专长杀跌
- 中线吸筹 (mid_accumulate): 3日预测，专长稳健
- 中线拉抬 (mid_pump): 3日预测，专长追涨
- 长线价值 (long_value): 5日预测，均衡全能
- 技术波段 (tech_swing): 3日预测，专长波动
- 暴力震仓 (aggressive_shake): 1日预测，专长杀跌
- 均衡全能 (balanced): 5日预测，均衡全能

### 评估维度
- direction_1d: 1日方向预测准确率
- direction_3d: 3日方向预测准确率
- direction_5d: 5日方向预测准确率
- direction_up: 上涨预测准确率
- direction_down: 下跌预测准确率
- volatility_match: 波动率匹配度
- stability: 价格稳定性
- composite: 综合评分

================================================================
  理解竞技场结果
================================================================

### 专家选拔

每个维度会选拔表现最好的组合作为"专家":
- 1日方向预测专家: 最擅长预测明日涨跌
- 3日方向预测专家: 最擅长预测3日内涨跌
- 5日方向预测专家: 最擅长预测5日内涨跌
- 波动率匹配专家: 最擅长匹配市场波动特征
- 综合专家: 各项指标综合最佳

### 集成推荐

集成推荐告诉你在不同场景下应该使用哪个组合:
- 短期追涨: 使用"短线追涨"或"中线拉抬"
- 短期杀跌: 使用"短线杀跌"或"暴力震仓"
- 中期布局: 使用"中线吸筹"或"技术波段"
- 长期持有: 使用"长线价值"或"均衡全能"

### 庄家行动预测

每个组合的庄家都有不同的行为模式:
- accumulate: 吸筹（暗中买入）
- hold: 持仓（观望）
- pump: 拉抬（拉升股价）
- distribute: 派发（高位出货）
- shake: 震仓（洗盘）

================================================================
  故障排除
================================================================

Q: 竞技场运行很慢怎么办？
A: 使用 --arena-combos 4 只运行前4个组合，或使用 --arena-profile 
   只运行单个组合测试。

Q: 实盘评估数据格式是什么？
A: 支持 .npy (numpy数组) 或 .csv (包含 close 或 price 列)

Q: 竞技场结果怎么看？
A: 运行 stock_interpreter.py --mode arena-report 生成格式化报告

Q: 某个组合表现很差怎么办？
A: 可能是参数不适合你的数据，可以调整 CombinationProfile 中的参数后重试

================================================================
  日更反馈系统 (★ v2.0 feedback_processor.py)
================================================================

### 核心概念

日更反馈 = 晚上一条龙 + 早上自动恢复

晚上维护时做：
  1. 增量数据更新 (baostock拉最新交易日数据)
  2. 解析反馈 (feedback.txt里的实盘交易)
  3. 评估信号 (对比系统信号vs实际盈亏)
  4. 校准参数 (调整庄散参数)
  5. 更新基准线 (最新实盘价格序列)
  6. 保存检查点 (模型权重+状态+校准参数)
  7. 生成早间恢复计划 (morning_resume.json)

早上恢复时做：
  1. 读取检查点 (模型权重)
  2. 应用校准参数
  3. 加载新基准线
  4. 快速热身 (50~100 episodes)
  5. 模型就绪，正常使用

================================================================
  日常命令
================================================================

### 晚上一条龙 (推荐)
python feedback_processor.py --mode daily

### 跳过数据更新 (只做反馈+校准+检查点)
python feedback_processor.py --mode daily --skip-data-update

### 跳过反馈 (只做数据更新+基准线+检查点)
python feedback_processor.py --mode daily --skip-feedback

### 早上恢复
python adversarial_env.py --mode resume

### 只增量更新数据
python feedback_processor.py --mode update-data

### 只更新基准线
python feedback_processor.py --mode update-benchmark

### 只保存检查点
python feedback_processor.py --mode checkpoint-save

### 只加载检查点看信息
python feedback_processor.py --mode checkpoint-load

### 监察反馈系统
python pipeline_monitor.py --focus feedback

================================================================
  反馈文件写法 (feedback.txt)
================================================================

格式: 日期 | 方向 | 代码 | 价格 | 数量 | 盈亏 | 备注

# 开头为注释
方向: 买入 / 卖出
盈亏: 卖出填实际盈亏金额，买入填0
备注: 自由文字(止损/止盈/追高/抄底等)

示例:
2026-06-23 | 买入 | 600519.SH | 1800.50 | 100 | 0 | 茅台，系统看多
2026-06-24 | 卖出 | 600519.SH | 1835.20 | 100 | 3470 | 茅台止盈

### 生成示例反馈文件
python feedback_processor.py --mode demo
