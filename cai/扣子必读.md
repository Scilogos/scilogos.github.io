## 三、实验设计

- **对照组**：纯DL基线（LSTM/Transformer），从历史数据端到端学习
- **实验组**：多智能体对抗模拟（庄家 vs 彩民）→ 策略迁移到实盘预测
- **检验方式**：两组在相同测试集上比较，配对t检验 + Wilcoxon + 效应量 + Bootstrap CI
- **Null Result 也是结果**：如果方法论经过正向对照验证但在真实数据上检测不到偏置，这是"彩票是纯随机的"的强证据

**详细设计**见 GitHub: `scilogos.github.io/cai/roadmap.md`

### API 访问要点（踩坑记录）

1. **福彩API反爬严格**：必须设置正确的 `Referer` 头（`https://www.cwl.gov.cn/ygkj/wqkjgg/{彩种}/`），否则返回403
2. **福彩API分页是假的**：`pageNo` 参数无效，每次都返回同样的数据。用 `issueCount` 控制拉取量
3. **体彩API分页正常**：`pageNo` + `pageSize` 可靠分页
4. **500彩票网**：双色球数据最全（2003年起），但3D/排列3/排列5的页面返回404
5. **排列5 完全不可用**：所有数据源均被封

### 定时更新

增量脚本已测试可用，可通过 Calendar 日程每天自动运行。脚本只发 HTTP 请求，**不消耗 DeepSeek 词元**，消耗少量扣子积分。

## 十、重要技术笔记

1. **庄家偏置实现**：温度采样 `P(i) ∝ exp(-β×投注量_i)`，β连续可调，β=0退化为纯随机
2. **策略型彩民**：多流派规则混合（追热/追冷/和值/走势/混合），贴近现实彩民行为
3. **正向对照必须做**：用已知β的合成数据验证方法论，否则 null result 无说服力
4. **Power Analysis**：效应量 d=0.2 时约需 198 期测试数据，排列3每天一期可行
5. **GitHub Pages 部署**：短时间多个 commit 会导致 artifact 冲突 → deploy 失败，避免频繁推送
