# 排列3对抗博弈模拟实验报告

## 实验概述

基于P0（数据采集）和P1（对照组）的结果，P2实验组引入**对抗博弈框架**，验证核心假设：

> **都市传说：彩票开奖是否倾向开出购买人数最少的号码？**

### 实验设计

| 角色 | 占比 | 策略 |
|------|------|------|
| **随机彩民** | 55% | LGBM追随(60%) + 追热(20%) + 追冷(10%) + 纯随机(10%) |
| **K策略彩民** | 20% | 5个精英智能体：freq_gap / cold_spot / ml_inverse / adaptive / meta |
| **R策略彩民** | 25% | 60个参数化智能体，每20轮进化一次 |
| **庄家** | — | 对抗模式：开总投注最少的号（95%理性+5%噪声）；对照组：纯随机 |

### K策略 vs R策略

| 维度 | K策略（精英型） | R策略（进化型） |
|------|----------------|----------------|
| 数量 | 5个 | 60个 |
| 设计理念 | 精心设计+少量淘汰 | 大量生成+达尔文筛选 |
| 参数来源 | 人工设计+自适应调整 | 随机初始化+遗传进化 |
| 适应性 | adaptive/meta可调权重 | 每20轮选择/交叉/变异 |
| 风格 | 高置信度买Top-5缺口 | 多样化参数探索 |

## 初步结果（500轮预测试）

### 对抗庄家模式

| 参与者 | ROI | 说明 |
|--------|-----|------|
| 庄家 | +75.5% | 利润率远超正常(48%) |
| 随机彩民 | -67.0% | 大幅亏损 |
| K策略 | -92.4% | 被庄家针对性碾压 |
| R策略 | -28.1%（最佳+4.2%） | 进化初期有个体命中，但整体仍亏 |

### 纯随机开奖对照组

| 参与者 | ROI | 说明 |
|--------|-----|------|
| 庄家 | ~48% | 正常彩票利润率 |
| 随机彩民 | ~-48% | 期望亏损 |
| 策略彩民 | ~-48% | 无法超越随机 |

## 核心发现

### 1. 对抗庄家下，庄家利润率从48%暴涨至75%+

当庄家能选择最少投注的号码时，利润率从正常的~48%升至~75%。这验证了假设：**如果庄家有选择权，他们确实会压榨彩民**。

### 2. K策略反被庄家利用

K智能体集中投注"缺口"号码 → 这些号码总投注变高 → 庄家故意避开 → K策略ROI=-92%。讽刺的是，**找缺口反而制造了缺口的对立面**。

### 3. R策略进化有效但不足以盈利

进化Gen17出现best_roi=+4.2的个体（某agent恰好命中直选），说明进化能筛选出短期有效的参数。但长期来看avg_roi仍趋向-28%，无法持续盈利。

### 4. 对抗 vs 随机的关键差异

- 随机开奖：所有策略≈-48%（公平的赌场）
- 对抗开奖：策略彩民亏损更严重（-92% vs -67%）
- **结论：在对抗环境中，策略反而有害**

## 下一步方向

1. **庄家噪声扫描**：测试noise=0.1~0.5，看在什么噪声水平下策略开始有效
2. **信息不对称实验**：庄家只能看到随机彩民的投注，看不到策略彩民
3. **协调博弈**：多个K智能体分散投注，避免集中化
4. **强化学习庄家**：庄家也用RL学习，形成真正的Nash均衡
