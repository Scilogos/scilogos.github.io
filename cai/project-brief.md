## 一、项目背景

本课程原定题目为"股票博弈"，因难度过高，经小组与老师协商后改为 **"彩票博弈"**。

小组共 **4 人**，组员账号已由 neko 统一管理。项目在**暑假期间完成**。

---

## 二、研究问题

### 核心问题

验证一个广为流传的都市传说：**彩票开奖会不会倾向于开出购买人数最少的那几个号码？**

即：开奖结果与投注分布之间是否存在统计学上的显著关联？

### 问题拆解

1. **零假设 (H₀)**：开奖号码完全随机，与投注分布无关
2. **备择假设 (H₁)**：开奖号码与投注分布存在某种关联（庄家可能倾向于开出少人买的号码以最大化赔付最小化）
3. 实验设计需排除"随机巧合"的干扰，用统计学方法严格检验

---

## 三、实验设计

### 对照实验结构

| 分组 | 方法 | 核心思路 |
|------|------|----------|
| **实验组 A** | 深度学习 (Deep Learning) | 用神经网络直接从历史开奖数据中学习号码模式，预测下一期号码 |
| **实验组 B** | 对抗学习 (Adversarial Learning) | 模拟"彩民 vs 庄家"博弈：彩民网络试图预测号码，庄家网络试图避开彩民预测，两方对抗训练 |

### 关键比较

- 若 H₀ 成立（开奖完全随机），两组预测准确率应无统计学差异
- 若 H₁ 成立（存在非随机模式），对抗学习组可能捕获"庄家策略"，预测表现与纯深度学习组产生显著差异
- 使用假设检验（t 检验 / Wilcoxon 检验等）判断两组预测结果之间是否存在统计学显著差异

### 实验变量

| 变量类型 | 具体内容 |
|----------|----------|
| 自变量 | 预测方法（深度学习 vs 对抗学习） |
| 因变量 | 预测准确率、与实际开奖号码的匹配度 |
| 控制变量 | 训练数据集、彩种、历史数据长度、网络架构复杂度 |

## 四、技术方案（框架）

### 4.1 数据来源

- **优先使用官方 JSON API**（免费、权威、无需注册）：
  - 福彩 API：`https://www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice`
    - 支持彩种：双色球 (`name=ssq`)、福彩3D (`name=3d`)、七乐彩 (`name=qlc`)
    - 参数：`issueCount`, `dayStart`, `dayEnd`
  - 体彩 API：`https://webapi.sporttery.cn/gateway/lottery/getHistoryPageListV1.qry`
    - 支持彩种：大乐透 (`gameNo=85`)、排列3 (`gameNo=35`)、排列5 (`gameNo=350`)、七星彩 (`gameNo=04`)
    - 参数：`pageSize` (最大100), `pageNo`
- 对应期次的投注分布数据（如能获取；否则用代理变量）
- 数据时间跨度：尽可能长（建议 ≥ 5 年）

> 详细 API 参数、示例代码和备选方案见 `lottery-rules.md` 第六部分。

### 4.2 实验组 A：深度学习预测

- **模型**：LSTM / Transformer 等序列模型
- **输入**：历史 N 期开奖号码序列
- **输出**：下一期号码的概率分布
- **训练**：标准监督学习，最小化预测分布与实际开奖的交叉熵

### 4.3 实验组 B：对抗学习预测

- **角色设定**：
  - **Generator（彩民）**：生成预测号码，目标是命中开奖结果
  - **Discriminator（庄家）**：判断哪些号码被彩民集中预测，倾向于避开热门号码
- **对抗机制**：Generator 学习预测号码，Discriminator 学习"反预测"策略，双方博弈达到 Nash 均衡
- **训练**：GAN 框架，交替优化 Generator 和 Discriminator

### 4.4 评估与统计检验

1. 在相同测试集上评估两组预测准确率
2. 配对 t 检验 / 非参数检验比较差异
3. 置信区间估计效应大小
4. 多彩种交叉验证（体彩 + 福彩不同游戏）

## 六、风险与挑战

1. **数据获取**：官方投注分布数据不公开，需寻找代理变量（如赔率变化、销量数据等）
2. **随机性本质**：若开奖确为完全随机，深度学习本身也无法学到有效模式，可能导致两组都"没有表现"，需考虑如何处理这种 null result
3. **统计功效**：样本量需足够大才能检测到微小效应
4. **对抗学习训练稳定性**：GAN 训练存在模式坍塌等已知问题
