# 中国彩票游戏规则汇编 — 体彩 & 福彩

> 本文档整理中国体彩和福彩主要游戏类别的投注规则与开奖规则，供"彩票博弈"项目研究参考。

---

## 第一部分：中国体育彩票（体彩）

体彩由国家体育总局体育彩票管理中心发行，目前主要游戏包括：

| 游戏名称 | 类型 | 开奖频率 | 号码结构 |
|----------|------|----------|----------|
| 超级大乐透 | 乐透型 | 每周一、三、六 | 前区5/35 + 后区2/12 |
| 排列3 | 数字型 | 每日 | 3位数字（000-999） |
| 排列5 | 数字型 | 每日 | 5位数字（00000-99999） |
| 7星彩 | 数字型 | 每周二、五、日 | 前6位(0-9) + 后1位(0-14) |
| 竞彩足球 | 竞猜型 | 赛事日 | 胜平负/比分/进球数等 |
| 竞彩篮球 | 竞猜型 | 赛事日 | 胜负/让分/大小分等 |
| 顶呱刮 | 即开型 | 随买随开 | 刮开覆膜兑奖 |

### 1. 超级大乐透

**投注规则**
- 前区：从 01-35 中选 5 个号码
- 后区：从 01-12 中选 2 个号码
- 组成"5+2"一注，每注 2 元
- **追加投注**：每注加 1 元，中一/二等奖时额外获得 80% 奖金

**投注方式**
- 单式投注：选5前+2后，1注
- 复式投注：前区选≥6个或后区选≥3个，系统自动组合
- 胆拖投注：选1-4个胆码+拖码组合

**开奖规则**
- 每周一、三、六开奖
- 公证人员监督，专用摇奖设备
- 从 01-35 随机摇出 5 个前区号码 + 从 01-12 随机摇出 2 个后区号码

**奖级设置**

| 奖级 | 中奖条件 | 奖金性质 |
|------|----------|----------|
| 一等奖 | 5前+2后全中 | 浮动（最高500万/注） |
| 二等奖 | 5前+1后 | 浮动 |
| 三等奖 | 5前 或 4前+2后 | 固定 3000元 |
| 四等奖 | 4前+1后 | 固定 500元 |
| 五等奖 | 4前 或 3前+2后 | 固定 30元 |
| 六等奖 | 3前+1后 或 2前+2后 | 固定 15元 |
| 七等奖 | 3前 或 2前+1后 或 1前+2后 或 2后 | 固定 5元 |

**中奖概率**
- 一等奖：1/17,721,088（约一千七百七十二万分之一）

**资金分配**
- 返奖率 51%（当期奖金 49% + 调节基金 2%）
- 发行费 13%
- 公益金 36%

---

### 2. 排列3

**投注规则**
- 从 000-999 中选取1个3位数
- 每注 2 元
- 支持多倍投注（2-99倍），单张彩票最高 20,000 元

**投注方式**

| 方式 | 说明 | 单注奖金 |
|------|------|----------|
| 直选（单选） | 号码数字和顺序完全一致 | 1,040 元 |
| 组选3 | 3位数中有2位相同（如112），顺序不限 | 346 元 |
| 组选6 | 3位数各不相同（如123），顺序不限 | 173 元 |

**开奖规则**
- 每日开奖一次（约 21:25）
- 以排列5当期开奖号码的前三位作为排列3开奖号码
- 开奖号码由摇奖设备产生，公证人员监督

**中奖概率**
- 直选：1/1,000
- 组选3：3/1,000 = 1/333
- 组选6：6/1,000 = 1/167

**资金分配**
- 返奖率 53%（当期奖金 52% + 调节基金 1%）

---

### 3. 排列5

**投注规则**
- 从 00000-99999 中选取1个5位数
- 仅设直选玩法（号码和顺序必须完全一致）
- 每注 2 元，固定奖金 **100,000 元**

**开奖规则**
- 每日开奖
- 专用摇奖设备从5组0-9中按顺序摇出5位数字

**中奖概率**
- 直选：1/100,000（十万分之一）

---

### 4. 7星彩

**投注规则**
- 前区：从 000000-999999 中选1个6位数字
- 后区：从 0-14 中选1个数字
- 组成"6+1"一注，每注 2 元

**开奖规则**
- 每周二、五、日开奖
- 从6组0-9中按顺序摇出6位前区 + 从0-14中摇出1位后区

**奖级设置**

| 奖级 | 中奖条件 | 奖金性质 |
|------|----------|----------|
| 一等奖 | 7位全部对应正确 | 浮动 |
| 二等奖 | 前6位全部正确 | 浮动 |
| 三等奖 | 前5位+后1位正确 | 浮动 |
| 四等奖 | 任意5位正确 | 固定 500元 |
| 五等奖 | 任意4位正确 | 固定 30元 |
| 六等奖 | 任意3位正确，或前1位+后1位，或仅后1位 | 固定 5元 |

**中奖概率**
- 一等奖：1/10,000,000（一千万分之一，前区1/1,000,000 × 后区1/10）

### 5. 竞彩足球/篮球

> 竞猜型彩票，不属于数字型随机开奖，本项目研究可能不适用，仅作了解。

**竞彩足球核心玩法**
- 胜平负：预测主队胜/平/负
- 让球胜平负：引入让球机制平衡实力差距
- 比分：预测精确比分
- 总进球数：预测全场进球总数
- 半全场胜平负：预测半场+全场赛果组合

**竞彩篮球核心玩法**
- 胜负：预测主队胜/负
- 让分胜负：引入让分机制
- 大小分：预测总分是否超过设定值
- 胜分差：预测胜队赢多少分

**特点**
- 赔率由官方设定，反映投注分布
- 支持单关和过关（串关）
- 开奖以赛事实际结果为准

## 第二部分：中国福利彩票（福彩）

福彩由中国福利彩票发行管理中心发行，目前主要游戏包括：

| 游戏名称 | 类型 | 开奖频率 | 号码结构 |
|----------|------|----------|----------|
| 双色球 | 乐透型 | 每周二、四、日 | 红球6/33 + 蓝球1/16 |
| 福彩3D | 数字型 | 每日 | 3位数字（000-999） |
| 七乐彩 | 乐透型 | 每周一、三、五 | 7/30 + 特别号1 |
| 快乐8 | 基诺型 | 每日 | 从1-80选1-10个，开出20个 |
| 刮刮乐 | 即开型 | 随买随开 | 刮开覆膜兑奖 |

---

### 1. 双色球

**投注规则**
- 红球区：从 01-33 中选 6 个号码
- 蓝球区：从 01-16 中选 1 个号码
- 组成"6+1"一注，每注 2 元

**投注方式**
- 单式：选6红+1蓝
- 复式：红球选≥7个或蓝球选≥2个
- 胆拖：红球选1-5个胆码+拖码，蓝球同

**开奖规则**
- 每周二、四、日 21:15 开奖
- 中国教育电视台（CETV-1）现场直播
- 摇奖机从01-33摇出6个红球 + 从01-16摇出1个蓝球

**奖级设置**

| 奖级 | 中奖条件 | 奖金 |
|------|----------|------|
| 一等奖 | 6红+1蓝 | 浮动（最高500万/注） |
| 二等奖 | 6红 | 浮动 |
| 三等奖 | 5红+1蓝 | 固定 3,000元 |
| 四等奖 | 5红 或 4红+1蓝 | 固定 200元 |
| 五等奖 | 4红 或 3红+1蓝 | 固定 10元 |
| 六等奖 | 2红+1蓝 或 1红+1蓝 或 仅1蓝 | 固定 5元 |

**中奖概率**
- 一等奖：1/17,721,088（C(33,6)×16 = 17,721,088）
- 整体中奖率：约 6.71%

**资金分配**
- 返奖率 51%（当期奖金 49% + 调节基金 2%）
- 发行费 13%
- 公益金 36%

---

### 2. 福彩3D

**投注规则**
- 从 000-999 中选取1个3位数
- 每注 2 元
- 支持多倍投注

**投注方式**

| 方式 | 说明 | 单注奖金 |
|------|------|----------|
| 直选（单选） | 号码数字和顺序完全一致 | 1,040 元 |
| 组选3 | 3位数中有2位相同，顺序不限 | 346 元 |
| 组选6 | 3位数各不相同，顺序不限 | 173 元 |
| 1D | 指定某一位猜中 | 较低 |
| 猜1D | 三位中任意一位含该数字即中 | 10 元（概率27.1%） |

**特殊投注**
- 拖拉机：三个号码为连续升/降序（如234、765），但890、098、901等不算
- 和值：三个数字之和
- 跨度：最大数字-最小数字

**开奖规则**
- 每日 21:15 开奖
- 北京摇奖大厅，公证人员监督，摇出3位中奖号码

**中奖概率**
- 直选：1/1,000
- 组选3：3/1,000 = 1/333
- 组选6：6/1,000 = 1/167

**资金分配**
- 返奖率 53%（当期奖金 49% + 调节基金 1% + 奖池余额）
- 每花100元，平均回本53元

### 3. 七乐彩

**投注规则**
- 从 01-30 共30个号码中选 7 个号码
- 每注 2 元

**投注方式**
- 单式：选7个号码
- 复式：选8-16个号码，系统自动组合
- 胆拖：选1-6个胆码+拖码

**开奖规则**
- 每周一、三、五 21:15 开奖
- 先摇出7个基本号码，再摇出1个特别号码
- CETV-1 直播

**奖级设置**

| 奖级 | 中奖条件 | 奖金 |
|------|----------|------|
| 一等奖 | 7个基本号码全中 | 浮动（最高500万） |
| 二等奖 | 6基本+1特别 | 浮动 |
| 三等奖 | 6基本 | 浮动 |
| 四等奖 | 5基本+1特别 | 固定 200元 |
| 五等奖 | 5基本 | 固定 50元 |
| 六等奖 | 4基本+1特别 | 固定 10元 |
| 七等奖 | 4基本 | 固定 5元 |

**中奖概率**
- 一等奖：1/2,035,800（约二百零四万分之一，C(30,7)）

**资金分配**
- 返奖率 50%（当期奖金 49% + 调节基金 1%）

### 4. 快乐8

**投注规则**
- 从 1-80 共80个号码中选 1-10 个号码
- 共十种玩法："选一"到"选十"
- 每注 2 元

**十种玩法概览**

| 玩法 | 选号个数 | 中奖条件 | 最高奖金 |
|------|----------|----------|----------|
| 选一 | 1 | 选的号在20个开奖号中 | 4.6元 |
| 选二 | 2 | 全部命中 | 19元 |
| 选三 | 3 | 全部命中 | 53元 |
| 选四 | 4 | 全部命中 | 140元 |
| 选五 | 5 | 全部命中 | 770元 |
| 选六 | 6 | 全部命中 | 3,080元 |
| 选七 | 7 | 全部命中 | 10,780元 |
| 选八 | 8 | 全部命中 | 51,040元 |
| 选九 | 9 | 全部命中 | 256,020元 |
| 选十 | 10 | 全部命中 | 500万元 |

**开奖规则**
- 每日 21:30 开奖
- 从 1-80 中随机摇出 20 个号码作为开奖号码
- 各期开奖结果完全独立

**关键概率**
- 选一中奖概率：25%（1/4）
- 选四综合中奖概率：25.89%

**特点**
- 不选的号也能中（选十玩法中，选的10个号一个没中也能获500元"全不中"奖）
- 灵活度最高，可策略性选号
- 返奖率约 58%

### 5. 刮刮乐（即开型）

**投注规则**
- 面值：5元、10元、20元、30元、50元等
- 购买后刮开覆盖膜即可知道是否中奖
- 即买即开，无需等待开奖

**特点**
- 返奖率约 65%（各类中最高）
- 无时间延迟，即时反馈
- 票面主题丰富
- 不适用时间序列预测研究

## 第三部分：本项目推荐彩种

基于"彩票博弈"研究需求（需要历史开奖数据 + 时间序列 + 投注分布），推荐以下彩种：

### 首选

| 彩种 | 推荐理由 |
|------|----------|
| **排列3 / 福彩3D** | 数字结构简单（3位数），每日开奖数据量大，固定赔率便于量化分析，投注分布数据更易获取 |
| **双色球 / 大乐透** | 关注度最高，社会讨论最多（与"都市传说"直接相关），数据历史长 |

### 次选

| 彩种 | 说明 |
|------|------|
| **快乐8** | 玩法复杂但数据维度丰富，"选十"的号码覆盖模式可做有趣分析 |
| **排列5** | 数据量大，但号码空间（10万种）较大，可能样本稀疏 |

### 不推荐

| 彩种 | 原因 |
|------|------|
| 竞彩足球/篮球 | 赛事型而非数字型，无随机开奖，不适合本实验设计 |
| 刮刮乐 | 无时间序列数据 |
| 7星彩 / 七乐彩 | 号码结构较特殊，数据量相对少 |

## 第四部分：关键数据获取渠道

| 数据 | 渠道 | 说明 |
|------|------|------|
| 历史开奖号码 | 体彩官网 lottery.gov.cn / 福彩官网 cwl.gov.cn | 免费，完整 |
| 销量数据 | 各期开奖公告中含全国销售总额 | 免费但不精细 |
| 投注分布（号码热度） | ❗ 难以获取 | 官方不公开具体号码投注分布，需寻找代理变量 |
| 赔率数据 | 竞彩赔率可从体彩官网获取 | 仅竞彩类有赔率概念 |
| 替代方案 | 彩票论坛/社区统计 | 非官方，质量参差 |

> **注意**：投注分布数据是本研究的关键瓶颈。官方不公开各号码的具体投注量，只有全国总销量。可能的替代方案：
> 1. 用销量数据 + 时间变量作为代理
> 2. 采集网络论坛"晒单"数据估算号码热度
> 3. 设计模拟实验：假设某种投注分布，验证算法检测能力
> 4. 联系体彩/福彩中心申请研究数据（需学校出具公函）

## 第五部分：开奖公平性保障机制

了解开奖流程对研究"庄家操控"假设至关重要：

1. **数据封存**：截止销售后，销售数据在公证人员监督下刻录不可改写光盘
2. **设备检测**：摇奖机为国际认证设备（如法国 AKANIS "托帕斯"），采用吹气式搅拌
3. **摇奖球管理**：球由特殊材料制作，严格统一尺寸/重量，公证人员保管
4. **直播开奖**：全程公证+电视直播
5. **独立计奖**：两组独立系统分别计奖，结果比对一致才算有效
6. **电子签名**：每张彩票含 SM2 算法电子签名，防篡改

> 以上机制表明，从流程设计上，开奖结果理论上应为纯随机。但本研究的价值正在于：**用数据科学方法实证检验这一理论假设**，而非仅凭流程描述做判断。
