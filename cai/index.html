量化经济与行为课程 Project — 彩票博弈：对抗模拟 + 实盘验证

🔬 研究问题

验证都市传说：彩票开奖是否倾向于开出购买人数最少的号码？
实验设计：先在模拟环境炼化庄家-彩民对抗智能体，再将训练策略迁移到真实数据预测；对照组用纯深度学习直接从历史数据学习。检验两组差异是否统计显著。

📋 对照组：纯深度学习
LSTM / Transformer 直接从历史开奖序列学习
输入：历史 N 期开奖号码
输出：下一期号码概率分布
本质：假设完全随机，端到端学习
⚔️ 实验组：对抗学习模拟
模拟彩票生态系统（规则参照排列3/3D）
彩民阵营：随机型 60-70% + 策略型 30-40%
庄家阵营：观察投注分布，倾向开出冷门号
对抗训练至策略收敛，再迁移到实盘
📊 统计检验
相同测试集（真实数据）上比较两组
配对 t 检验 / Wilcoxon 检验
多彩种交叉验证
若 H₀ 成立（纯随机），两组无显著差异

关键风险
⚠️ 投注分布数据
官方不公开各号码具体投注量，只有全国总销量。本方案走模拟路线：设计典型投注分布假设，在模拟环境中验证方法论的检测能力。
⚠️ Null Result 处理
若开奖确为纯随机，两组都无法学到有效模式。需设计好 null result 的报告框架，这本身也是有价值的科学结论。建议加正向对照实验（合成数据）验证方法论。
⚠️ 模拟→实盘迁移
模拟环境训练出的策略能否泛化到真实数据是关键挑战。需谨慎设计迁移方案，并评估模拟假设与现实的偏差。
